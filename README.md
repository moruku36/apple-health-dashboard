# ⌚ Apple Watch & 体組成計 Health Dashboard (Pro / AI Insights)

Apple Watch および iPhone ヘルスケアの生体データ（8年分・600万件超）と、フィットネスクラブ（ティップネス Dr.フィットネス / InBody）の**体組成測定データ（体重・骨格筋量・体脂肪率・SMI・部位別筋量など）**を安全かつ美しく一元管理・可視化するモダンな PWA 対応 Web ダッシュボードです。

---

## 🌟 主な機能と特徴

### 1. 🏋️ 体組成計（Dr.フィットネス / InBody）月次トラッキング 【NEW】
- **多項目測定データの可視化**:
  - 体重、BMI、体脂肪率、体脂肪量、筋肉量、骨格筋量（SMM）、フィットネススコア、内臓脂肪レベル、基礎代謝（BMR）、骨格筋指数（SMI）、体組成4大要素（水分・たんぱく質・ミネラル・体脂肪）。
- **月次推移 & 前回比（Diff）分析**:
  - 過去の測定日（6/8、8/22 等）を即座に切り替え、前回からの増減（`+5.6kg 体重`, `+1.7kg 骨格筋量UP`, `+6pt スコア改善`）を視覚的に把握。
- **部位別 筋肉量 & 脂肪量チャート**:
  - 右腕・左腕・体幹・右脚・左脚の筋肉バランスと脂肪分布をグラフ表示。
- **サルコペニア & 体型バランス判定**:
  - 骨格筋指数 SMI（8.5 kg/m² で同年代平均 8.1 を上回り良好）、筋肉量上下左右バランス判定（標準型）。
- **➕ 毎月の測定データ簡単記録機能**:
  - ダッシュボード上の「**新しい測定データを記録**」ボタンから、次月以降の測定数値をフォーム入力して「保存」するだけで、ブラウザ内で即座に暗号化データに統合・蓄積されます。

### 2. 🔒 クライアントサイド AES-256-GCM 暗号化 & セキュリティ
- 個人生体データは **PBKDF2（100,000回反復 + SHA-256）+ AES-256-GCM** で強力に暗号化。
- ブラウザ標準の **Web Crypto API** でクライアント側でのみ復号されるため、GitHub Pages 等でソースが公開されても第三者にデータが見られることはありません。
- **Touch ID / Face ID（生体認証）**: WebAuthn 対応端末では、パスワード入力不要のワンタッチログインが可能。
- **パスワード変更（再暗号化）**: 設定パネルから新しいパスワードを入力して即座に再暗号化できます。

### 3. 🧠 AI ヘルスアナリティクス & コンディション診断
- **総合コンディションスコア（100点満点）**: 安静時心拍数、自律神経（HRV）、睡眠時間、歩数から日々のリカバリー度・コンディションを自動スコアリング。
- **ヘルスアラート & トレンド診断**: 心肺機能・自律神経回復力・睡眠クオリティの変化を自動検知してアドバイスを表示。

### 4. 🌿 GitHub風 年間アクティビティ・ヒートマップ（草カレンダー）
- 年間365日の日々の歩数とワークアウト実績を 5段階のカラースケールでタイル表示。
- 年切り替え（2026年、2025年、2024年...）やマウスホバーによる日別詳細表示に対応。

### 5. 📊 豊富なヘルスケア指標 & インタラクティブ可視化
- **概要 & 目標**: 生涯歩数・距離・カロリー・1日歩数目標＆睡眠目標プログレスゲージ。
- **運動 & 歩数**: 月別1日平均歩数、活動カロリー＆運動回数、曜日別傾向、歩行安定性 / 非対称性（%）、**前年同月比（YoY）オーバーレイ比較**、**ピンチズーム・パン対応**。
- **心拍 & バイタル**: 安静時心拍数 ＆ 心拍変動（HRV: SDNN）、血中酸素ウェルネス（SpO2 %）＆ VO2Max 推移。
- **睡眠 & ステージ**: 月別平均実睡眠時間（推奨基準ガイドライン付き）、睡眠ステージ内訳（深い睡眠 / コア / レム睡眠）。
- **ワークアウト**: 種目別内訳（ドーナツチャート）、全ワークアウト履歴（日付・種目検索＆フィルタ機能）。

### 6. 📱 モバイル & PWA UX
- **スワイプナビゲーション**: 画面左右のスワイプ操作で指1本でタブをシームレスに切り替え。
- **カラーテーマ切り替え**: `Midnight Blue`（標準）、`OLED Pure Black`（省電力・漆黒）、`Emerald Forest`（深緑系）。
- **PWA 完全オフライン対応**: Service Worker（`sw.js`）により、電波の届かないオフライン環境でも瞬時に起動。

## 🔄 データの更新方法

### 体組成計データの追加（毎月1回の測定後）
1. ダッシュボードの「**体組成計**」タブを開く。
2. 「**＋ 新しい測定データを記録**」ボタンをクリック。
3. カルテに記載された測定日・体重・体脂肪率・骨格筋量・スコア等の数値を入力して「保存」をクリック。
4. 自動で暗号化・画面が更新されます。「更新済み index.html をダウンロード」して GitHub にプッシュすれば公開サイトにも反映されます。

### Apple Health データ（歩数・心拍・睡眠等）の更新
- ダッシュボードのヘッダーにある「**データ更新**」ボタンから、iPhoneの `export.zip` をドラッグ＆ドロップするだけで、ブラウザ内で即座に自動集計・再暗号化されます。

## 🚀 GitHub Pages での公開手順（無料・1クリック）

1. このリポジトリをご自身の GitHub アカウントにプッシュします。
2. GitHub リポジトリの **Settings**（設定）タブを開きます。
3. 左メニューの **Pages** を選択します。
4. **Build and deployment** > **Source** で `Deploy from a branch` を選択します。
5. **Branch** で `main` / `/ (root)` を選択して **Save** をクリックします。
6. 数分後に発行される URL（`https://<username>.github.io/<repo-name>/`）にアクセスすれば、世界中どこからでも安全に閲覧できます！
